# Machine Learning (ML) Pipelines

## Overview
The `ml/` directory contains all model development assets, including data preparation routines, exploratory notebooks, anomaly detection algorithms, attack classification models, temporal forecasting architectures, and evaluation suites.

## Directory Structure
- `notebooks/`: Exploratory data analysis (EDA), prototype models, and experimental research notebooks.
- `preprocessing/`: Scripts for data cleaning, flow feature transformation, and time-window construction.
- `anomaly_detection/`: Unsupervised and semi-supervised anomaly detection routines.
- `attack_classification/`: Supervised multi-class classifiers for threat attribution.
- `forecasting/`: Temporal sequence models forecasting future attack risk horizons.
- `evaluation/`: Benchmark metrics, confusion matrices, ROC/PR curves, and evaluation runners.
- `models/`: Destination directory for serialized model artifacts (`.joblib`, `.pt`). (Git-ignored).
