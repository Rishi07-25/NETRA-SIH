# Behavioral Anomaly Detection

## Overview
This module trains and deploys unsupervised or semi-supervised anomaly detection models to detect abnormal traffic deviations from benign baseline behavior.

## Components
- `train.py`: Model training loop for anomaly algorithms (Isolation Forest, One-Class SVM, Autoencoder).
- `predict.py`: Real-time anomaly scoring pipeline producing normalized anomaly probabilities.
