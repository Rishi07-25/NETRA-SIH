# Attack Classification

## Overview
This module classifies suspicious network behaviors into recognized threat categories (such as Reconnaissance, Brute Force, Denial of Service, and Exploitation).

## Components
- `train.py`: Supervised model training on labeled flow records using algorithms like XGBoost, LightGBM, and Random Forest.
- `predict.py`: Multi-class threat classification pipeline outputting class probabilities and confidence scores.
