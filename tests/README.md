# Testing & Quality Assurance

## Overview
This directory houses integration and end-to-end (E2E) test suites ensuring synchronization across data generation, ML inference, API communication, and frontend interfaces.

## Directory Structure
- `integration/`: Tests verifying multi-service integrations (e.g., flow ingestion to backend schemas, database storage).
- `end-to-end/`: Complete workflow tests evaluating scenarios from synthetic PCAP generation through the threat forecasting pipeline to API alerts.
