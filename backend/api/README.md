# API Route Controllers

## Overview
This package defines the route handlers for each logical domain of NETRA's API.

## Endpoints
- `predict.py`: Attack classification and threat inference routes.
- `forecast.py`: Temporal attack risk forecasting routes across upcoming time horizons.
- `anomaly.py`: Outlier detection and baseline deviation endpoints.
- `network.py`: Network flow statistics, throughput metrics, and interface status.
- `events.py`: Incident feed, alert history, and warning notifications.
