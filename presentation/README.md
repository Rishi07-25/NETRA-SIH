# Presentation & SIH Deliverables

## Overview
This directory organizes all presentation deliverables, pitch decks, slide templates, architectural visual assets, and speaker scripts for jury evaluations.

## Directory Structure
- `ppt/`: PowerPoint (`.pptx`) and PDF slide decks.
- `assets/`: Logos, team branding, badges, and presentation icons.
- `diagrams/`: High-resolution architectural flowcharts, kill-chain diagrams, and system blueprints.
- `speaker-notes.md`: Scripted speaker speaking tracks and timing breakdown for the team pitch.
