# NETRA Documentation

## Overview
This directory contains technical specifications, architecture diagrams, mathematical formulations, and research collateral supporting the **NETRA (Network Threat Early-warning & Risk Analytics)** project for **SIH26153**.

## Directory Index
- [`problem-statement.md`](problem-statement.md): Analysis of SIH Problem Statement SIH26153 from NTRO.
- [`solution-overview.md`](solution-overview.md): High-level operational concept and solution lifecycle.
- [`system-architecture.md`](system-architecture.md): Overall modular software architecture and inter-service communications.
- [`ai-architecture.md`](ai-architecture.md): Pipeline design for anomaly detection, attack classification, and risk forecasting.
- [`cybersecurity-analysis.md`](cybersecurity-analysis.md): Threat modeling, MITRE ATT&CK alignment, and network security considerations.
- [`dataset-documentation.md`](dataset-documentation.md): Candidate benchmark datasets, flow telemetry specifications, and schema notes.
- [`api-documentation.md`](api-documentation.md): Specification of backend REST endpoints, payloads, and communication protocols.
- [`research-and-references.md`](research-and-references.md): Academic literature, IEEE/ACM citations, and state-of-the-art references.
- [`novelty.md`](novelty.md): Key differentiating factors, innovation vectors, and technological advantages of NETRA.
- [`judge-qa.md`](judge-qa.md): Preparation handbook addressing technical, operational, and practical jury inquiries.
